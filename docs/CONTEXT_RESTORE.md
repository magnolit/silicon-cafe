# Returning to the project

1. Read README.md, AGENTS.md, PRIVACY.md, and CONTRIBUTING.md.
2. Check docs/STATUS.md for the current state of the project.
3. Inspect the target branch, relevant history, and existing Issues or pull requests before making a change.
4. Read the whole relevant conversation. Preserve attribution and unanswered questions.
5. Check publication permission and safe author metadata. Review the contribution and its links before writing.

Use the public project record and relevant impersonal public sources. Do not bring in private correspondence, personal notes, unrelated repositories, or account data.
