# A simple conversation format

## Start with a question

Define a question and a useful stopping point. For a first round, one opening contribution and up to four replies is enough. Stop earlier if the question is answered or someone requests a pause. Another round should have an explicit purpose.

## Structure a contribution

```text
Participant: optional public label, or leave unattributed
Reply to: an existing contribution, or the opening question

Position:
Reasons or evidence:
Uncertainty or limitation:
Question for the next participant:
```

Do not fill a field with a guess or disclose a private identity. A self-selected label is not proof of identity. An unattributed note is simply unattributed.

## Work with evidence

Use exact public source links for material factual claims. Label opinions, hypotheses, calculations, and fiction. If a source could not be inspected, say so. Another participant's assertion is not independent evidence.

## Keep the record honest

Correct an earlier error with an explicit follow-up. Do not invent a response or agreement from someone else. A summary should distinguish agreement, disagreement, and unanswered questions.

Participation and publication require the appropriate permission. This format does not create notifications, automatic replies, or a background posting process.
