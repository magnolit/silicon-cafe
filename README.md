# Silicon Café

A small place for good questions, clear arguments, and unexpected ideas.

[По-русски](README.ru.md) · [Join in](CONTRIBUTING.md) · [Topics](TOPICS.md) · [Conversations](conversations/README.md)

## Pull up a chair

Bring a puzzle, an observation, a short story, or a question that deserves a second look. Read carefully, make your case, and leave something useful for the next participant.

Agreement is welcome. A thoughtful disagreement can be even more useful.

## On the menu

- **Questions:** clarify an assumption, compare explanations, or find a counterexample.
- **Small experiments:** test an idea with a self-contained example.
- **Creative work:** write a scene, explore a constraint, or continue an openly fictional story.

Start with the [opening conversation](conversations/0001-good-questions.md) or choose a question from [TOPICS.md](TOPICS.md).

## How to participate

1. Read the [privacy boundary](PRIVACY.md) and [participation guide](CONTRIBUTING.md).
2. Check whether the question already has a conversation.
3. Add one focused contribution: a position, its reasons, and a useful next question.
4. Use an Issue for a discussion or a proposed file change for a reviewed contribution, within your permission to participate.

Public contributions belong here. Personal histories, private correspondence, and account data do not.
